# Анализ отзывов на игры

Скрипт для автоматического анализа отзывов об играх через LLM. Определяет оценку, темы и кратко пересказывает суть отзыва. Результат выводится в файлы формата JSON и TXT.

Проект предназначен для аналитики пользовательского опыта и разработчиков, которым требуется обработка больших объёмов текстовых отзывов

В папке "примеры" можно найти примеры входных и выходных файлов, полученных через этот скрипт

## Основные функции

- Чтение данных с файлов форматов CSV или TXT
- Анализ тональности и затрагиваемых аспектов в отзыве, с выводом краткого содержания в одно предложение
- Вывод в 2 форматах: TXT для удобного отображения и JSON для машиной обработки
- Прогресс анализа нескольких ответов сохраняется и можно возобновить без потери обработанных данных

## Технические характеристики

- язык реализации - Python
- API провайдер -Openrouter
- используемая модель - Minimax m2.5 free

## Этапы работы

Скрипт выполняет следующие этапы:
1. Обнаружение входного файла и загрузка данных
2. Для каждого отзыва: формирование запроса к LLM с фиксированным промптом
3. Парсинг ответа, валидация полей (sentiment, topics, summary, confidence)
4. Сохранение промежуточных результатов после каждого отзыва
5. Генерация итоговой статистики и текстового отчёта

## Инструкция к запуску

### Подготовка входных данных

Для работы необзодимо загрузить в папку проекта один файл TXT с названием "review", либо один CSV файл с названием "reviews" и обязательной колонкой "review" или "text", в которой содержатся текстовые отзывы. Если в папке находятся оба файла разных форматов, то приоритет отдаётся файлу CSV

### Настройка API-ключа

Необходимо содать файл .env в корневой директории проекта. В нём будет содержытся информация о вашем ключе, что необходимо для работы скрипта.

В файл необходимо вставить одну строчку, в конце которой нужно вставить информацию о ключе, без пробелов и скобочек
OPENROUTER_API_KEY=(ваш ключ)

#### Как получить ключ и доступ к OpenRouter

Для работы скрипта требуется API-ключ сервиса OpenRouter, предоставляющего доступ к моделям LLM через единый интерфейс. Если у вас нет ключа и вы не зарегестрированы,то
1-Перейдите на официальный сайт openrouter.ai
2-Выполните регистрацию. Сервис поддерживает создание аккаунта через электронную почту, а также через аккаунты Google или GitHub
3-После успешной регистрации и входа в личный кабинет перейдите в раздел API Keys
4-Нажмите кнопку Create Key для генерации нового ключа
5-Скопируйте полученный ключ и сохраните его. Он имеет формат: sk-or-v1-...

### Запуск скрипта

 В итоге, перед запуском у вас должна быть следующая структура файлов:

 проект/
│
├── main.py
├── .env
│
├── reviews.csv   (либо review.txt)

 Если всё верно, то при запуске main.py будет выводится консольный вывод с этапами работы обработанных отзывов. По запершению, будут созданы два файла: 
-analysis_results.json — структурированные данные в формате JSON
-analysis_report.txt — читаемый текстовый отчёт
